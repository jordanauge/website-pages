"FluidNC plugin: automated workpiece zeroing with touch plates"

2026-05-14 2026-11-09 CNC
Summary

A FluidNC plugin that generates G38.2 probing sequences for four touch plate types. Includes a 3D model of the Sienci AXTP-0002 AutoZero plate in the desktop simulator with shape-aware collision detection and smooth animation.

Why

Every CNC job starts the same way: setting the work zero. You jog the tool down, slip a piece of paper under the bit, lower until it grabs — and hope you got within 0.1 mm. For Z-only work it’s tolerable. For three-axis corner probing it’s tedious and error-prone.

Touch plates automate this. A conductive plate of known thickness sits on the workpiece (or at its corner), and the machine probes until contact. FluidNC supports G38.2 probing natively, but there is no built-in workflow to chain the right sequence of moves — Z probe, retract, move to X face, probe X, retract, move to Y face, probe Y — while compensating for plate thickness and tool radius.

This plugin generates and injects complete probing sequences for four gSender-compatible touch plate types.

Supported plates

Plate Modes Z thickness XY thickness
Standard Block Z-only, XY-only, XYZ corner 15.0 mm 10.0 mm
Sienci AutoZero XYZ bore center-find 5.0 mm 22.5 mm
Z Probe Z-only 15.0 mm —
BitZero V2 (Carbide3D) Z-only or XYZ bore 15.5 mm 15.0 mm bore

All Z probes use two-speed probing: fast seek to find the surface, retract, then slow precision pass. XY probes compensate for tool diameter automatically.

  plate_width_mm: 50.0
  plate_length_mm: 50.0

Changing plate_type automatically loads the correct default thicknesses. Override individual values as needed.

Usage without a display

Trigger probing via the WebUI serial console or a G-code macro. The plugin’s generate_probe_gcode(ProbeMode) method returns a complete sequence of G-code lines:

1
2
3
4
// Example: trigger XYZ corner probing from a macro
AutoZero* az = ...;  // from FluidNC module registry
std::string gcode = az->generate_probe_gcode(AutoZero::ProbeMode::XYZ);
// gcode is injected into the command channel

The sequence handles all movements, probing, thickness compensation, and WCS offset writes (G10 L20 P0).

Before probing starts, the extension performs a continuity check: it reads the probe input pin to verify the circuit is not already closed (plate touching the tool before the sequence begins). If continuity is detected, the probe refuses to start and displays an alert.

Interoperability with StallGuard

When fluidnc-stallguard is also compiled, a stall during the fast seek phase triggers an automatic Feed Hold — protecting against crashes if the plate is closer than expected. The AZ tab shows “SG backup active” when this integration is available.

Four corners

The Standard Block plate supports probing from any of the four workpiece corners. The corner setting (0–3) controls the direction of XY probe moves:

Corner X direction Y direction
0 — Bottom-Left +X → probe -X face +Y → probe -Y face
1 — Top-Left +X → probe -X face -Y → probe +Y face
2 — Top-Right -X → probe +X face -Y → probe +Y face
3 — Bottom-Right -X → probe +X face +Y → probe -Y face

Testing in the Simulator

The fluidnc-sim desktop simulator includes a fully functional 3D model of the Sienci AXTP-0002 AutoZero plate with contact detection. You can visualize probe sequences and validate G-code generation:

# Build simulator with AutoZero support
cd fluidnc-sim && cmake --build build
./build/fluidnc-sim fixtures/ttc450-cnc.yaml

# In the simulator, load a demo probe sequence:
# - Open a GCode console and run: M300 Z-30 (simulated Z probe)
# - Watch the 3D model detect contact with the AutoZero pocket
# - See the intermediate waypoints (~50 steps) for smooth animation

The simulator also supports all four plate types (Standard Block, AutoZero, Z Probe, BitZero V2) in the 3D view. This allows testing probe logic and XYZ corner sequences before hardware deployment.
